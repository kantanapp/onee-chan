# おはなしの ほんだな

スマホで読む紙芝居アプリです。本棚から おはなしを選び、指でスライドしてページをめくると、
文章を読み上げます。

**https://kantanapp.github.io/onee-chan/**

## 入っている おはなし

- おねえちゃんと いっしょ（トマトが苦手な姉妹の話）
- まるい まどの ドーナツ（ドーナツの穴から家族をのぞく話）

## おはなしを 増やすとき

1. `works/` の中に新しいフォルダを作り、その中の `img/` に絵を入れる
   （`0.jpg` が表紙、`1.jpg`、`2.jpg`… が本文）
2. `works.js` を開き、いちばん近い形の作品をまるごとコピーして、
   `id`・`title`・`lead`・`pages` を書き替える
3. GitHub にアップロードすると、1〜2分で公開ページに反映されます

`index.html` は触らなくて大丈夫です。

## 絵を差し替えるとき

`works/<おはなしのid>/img/` の中の同じ名前の画像を上書きしてください。
